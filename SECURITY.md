# Security policy

## Supported versions

Only the latest version of each mod gets security fixes. Check yours with `/plugin` in Claude Code.

## Report a vulnerability

Report it privately, never in a public issue:

1. **On GitHub:** select **Report a vulnerability** on the [Security tab](https://github.com/andrej-kolic/claude-mods/security). The report stays private until a fix is published.
2. **Without a GitHub account:** email andrej.kolic+claude-mods-security@gmail.com.

Include the mod and its version, your Claude Code version, and steps to reproduce. Expect a first reply within a week.

Mods run unsandboxed, with your user's permissions. Report anything that makes a mod read, keep, send or change data beyond what its README says it does.
